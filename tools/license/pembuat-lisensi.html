Pembuat Lisensi KLM Kinetic Live Mixer

Berjalan 100% offline di browser ini. Kunci privat hanya dibaca ke memori, tidak disimpan dan tidak dikirim ke mana pun.

1 · Kunci privat penjual

Pilih file klm-mix-private-key.jwk.json atau klm-mix-private-key.pem. Jangan pernah membagikan file ini.

2 · Data pembeli

Lisensi berlaku seumur hidup untuk komputer tersebut, termasuk setelah Windows di-install ulang (Device ID diambil dari perangkat keras).

3 · Kunci lisensi

Kirim kunci atau file .klmlic ke pembeli. Di KLM: Bantuan → 🔑 Lisensi, Pengaturan → Lisensi, atau tombol 🔒 Aktifkan di bar atas → tempel kunci → Aktifkan.
